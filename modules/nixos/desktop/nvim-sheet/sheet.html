nvim cheatsheet

built-ins + your config

01 Modes

The same key does different things depending on the mode. You start in Normal mode, and Esc always brings you back.

Normal
Keys are commands: move, delete, copy. This is home base.
Insert
Keys type text. Enter it with i, a or o.
Visual
Select text, then act on it. Enter it with v, V or Ctrlv.
Command
Press : and type a command such as w (save), then Enter.
Terminal
Inside :terminal. Leave it with Ctrl\ Ctrln.

02 Reading the notation

Keys inside < > are a single key or a held chord. Everything else is a plain key, pressed one after another.

Ctrlw
<C-w>: hold Ctrl, tap w, then let go. Like Ctrl+C anywhere else.
Ctrlw v
<C-w>v: Ctrl+w, release, then tap v. Two separate presses.
g g
gg: tap g twice. Nothing is held.
G
A capital letter means Shift+that letter, so G is Shift+g.
Space
<leader> is a key you choose. In your config it's Space, so <leader>ff is Space, f, f.
ShiftTab Altq
<S-…> is Shift, <A-…> or <M-…> is Alt, <CR> is Enter.
{char}
A placeholder you fill in: f{char} could be f(.

03 Prefix families

Most keybindings belong to a few families. Once you know the family, the rest of the binding is easy to guess.

Ctrlw
Windows (splits): create, move between, close and resize them. Every split command starts with it.
Space
Your commands, all from plugins: f find, b buffers, g git, h hunks, d debug, m cmake, v vault, u toggles.
g
"Go" / extra commands: gg top, gd definition, gc comment, gx open link.
z
View, folds and spelling: zz center, za fold, z= fix spelling.
[ ]
Previous / next something: ]d diagnostic, ]b buffer, ]c git change.
"
Pick a register (clipboard slot) before a copy, delete or paste.
:
Command line: type a command, press Enter.

04 The grammar: verb + count + noun

Most of Vim follows one pattern. An operator (the verb) waits for a motion or text object (the noun). Learn 5 verbs and 10 nouns and you get 50 commands. Try it:
