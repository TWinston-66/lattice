01 Modes

The same key does different things depending on the mode. You start in Normal mode, and Esc always brings you back.

Normal
Keys are commands: move, delete, copy. This is home base.
Insert
Keys type text. Enter it with i, a or o.
Visual
Select text, then act on it. Enter it with v, V or Ctrlv.
Command
Press : and type a command such as w (save), then Enter.
Terminal
Inside :terminal. Leave it with Ctrl\ Ctrln.

02 Reading the notation

Keys inside < > are a single key or a held chord. Everything else is a plain key, pressed one after another.

Ctrlw
<C-w>: hold Ctrl, tap w, then let go. Like Ctrl+C anywhere else.
Ctrlw v
<C-w>v: Ctrl+w, release, then tap v. Two separate presses.
g g
gg: tap g twice. Nothing is held.
G
A capital letter means Shift+that letter, so G is Shift+g.
Space
<leader> is a key you choose. In your config it's Space, so <leader>ff is Space, f, f.
ShiftTab Altq
<S-…> is Shift, <A-…> or <M-…> is Alt, <CR> is Enter.
{char}
A placeholder you fill in: f{char} could be f(.
On this MacBook's own keyboard, Ctrl is the ⌘ key beside the space bar.

03 Prefix families

Most keybindings belong to a few families. Once you know the family, the rest of the binding is easy to guess.

Ctrlw
Windows (splits): create, move between, close and resize them. Every split command starts with it.
Space
Your commands, all from plugins: f find, b buffers, g git, h hunks, d debug, m cmake, v vault, u toggles.
g
"Go" / extra commands: gg top, gd definition, gc comment, gx open link.
z
View, folds and spelling: zz center, za fold, z= fix spelling.
[ ]
Previous / next something: ]d diagnostic, ]b buffer, ]c git change.
"
Pick a register (clipboard slot) before a copy, delete or paste.
:
Command line: type a command, press Enter.

04 The grammar: verb + count + noun

Most of Vim follows one pattern. An operator (the verb) waits for a motion or text object (the noun). Learn 5 verbs and 10 nouns and you get 50 commands. Try it:

05 A learning path

Don't learn it all. Take one step a week, use those keys until they're automatic, then move on. Click a key to find it below, and tick its row off when it sticks. A step goes green when every key in it is ticked.

01 Sessions, windows, panes

tmux runs inside foot and keeps your terminals alive, even when the window closes.

SessionA project: a set of windows with one name. Survives closing the terminal; resurrect and continuum restore it after a reboot.
WindowA full-screen tab in the session, listed along the bottom bar.
PaneOne terminal inside a window. Split a window to get more.

02 The prefix: Ctrl+a

Almost every tmux key starts with the prefix, so tmux doesn't steal keys from the programs inside it.

Ctrla c
C-a c: hold Ctrl, tap a, let go, then tap c.
Ctrla Ctrla
Twice sends a real Ctrl+a to the program: the shell's start of line.
Altw
M-w is Alt+w (M for Meta).
Ctrla ?
Lists every key tmux knows, defaults included.
On this MacBook's own keyboard, Ctrl is the ⌘ key, so the prefix is ⌘+a.

03 Copy mode

Scrollback lives in copy mode. Scroll the wheel up or press Ctrla [ to get in, and q to get out.

Your tmux uses emacs-style copy keys: CtrlSpace starts a selection and Altw copies it. Dragging with the mouse selects and copies straight to the clipboard, and double-click copies a word.

04 tmux splits or nvim splits?

Both split the screen, but they split different things.

nvim splits (Ctrlw v) are views into files, all inside one nvim. Use them to read two files side by side. tmux panes (Ctrla \) are separate terminals. Use them to keep a dev server, tests or git running next to your editor. The rows below come straight from tmux list-keys and keys.tsv, the same rows Super/ searches.

01 The SUPER key

Nearly every desktop key is SUPER plus something, so it never clashes with keys inside apps.

Add Shift to a SUPER key and it usually moves the window instead of the focus: SUPER+3 goes to workspace 3, SUPER+Shift+3 sends the window there.

On this MacBook's own keyboard, SUPER is the corner key labelled control, and Ctrl is ⌘ (hid_apple swaps them). An external non-Apple keyboard keeps its normal keys.

02 Workspaces

Numbered desktops, each with its own windows. A 3-finger swipe moves between them.

The scratchpad is a hidden workspace that slides over whatever you're doing: park a terminal or a music player there and toggle it with SUPER+S.

03 Tiling

New windows tile on their own, side by side. You don't drag them around.

Float one with SUPER+V, fill the screen with SUPER+F, and flip how a pair is split with SUPER+J. SUPER+R enters resize mode: arrows resize, Esc leaves. SUPER plus a mouse drag moves or resizes anything.
